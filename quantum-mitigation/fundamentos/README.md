# Fundamentos

Esta pasta reúne o que é preciso saber para ler os experimentos. Cada arquivo é curto e independente.

| Arquivo | Pergunta que responde |
| --- | --- |
| [ruido.md](ruido.md) | De onde vem o desvio entre o resultado ideal e o medido? |
| [tecnicas.md](tecnicas.md) | Que técnicas reduzem esse desvio, qual delas já testamos e quais ainda faltam? |
| [indicadores.md](indicadores.md) | Como medimos o desvio no GHZ (PZ e CX) e como calculamos a incerteza? |
| [referencias.md](referencias.md) | Em quais trabalhos cada técnica se apoia? |

**Para expandir.** Uma técnica nova entra como uma linha em [tecnicas.md](tecnicas.md) e, quando for testada, ganha uma pasta em [experimentos](../experimentos/README.md). Um circuito novo entra em [indicadores.md](indicadores.md), com seu resultado ideal e seu indicador.
